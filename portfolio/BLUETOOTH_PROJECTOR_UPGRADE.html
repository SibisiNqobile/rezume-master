Projector Web interface and Thermal Control Module

An IoT hardware upgrade adding dynamic fan control, wireless connectivity, and custom web management.

Technologies Used

  • ESP32 (Wi-Fi & Bluetooth)
  • C / C++ (Embedded Firmware)
  • USB-C to UART Bridge
  • Optoelectronics / Optocouplers
  • PWM Thermal Fan Control
  • HTML5 / Web Dashboard

Project Overview

After purchasing a budget Telefunken projector, I identified several hardware limitations that impacted usability—primarily excessive fan noise and a weak infrared remote that required close proximity to the receiver. To solve these pain points and introduce smart home integration, I implemented the following upgrades:

  • Thermal Management: Reduced noise levels by implementing a smart temperature-monitoring system that dynamically adjusts fan RPM based on real-time system thermals.
  • USB to UART Interface: Added a USB-C to UART interface to simplify firmware uploading, debugging, and future updates.
  • Wireless Control: Replaced the weak IR receiver with Bluetooth and Wi-Fi connectivity for seamless command execution.
  • Web Interface: Developed a responsive web dashboard to monitor and manage the projector control module remotely.
